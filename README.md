# 顕微鏡 TIFF から4枚組の図を作る

Windows の PowerShell で実行します。

```powershell
cd C:\Users\porig\Documents\laboratory\codes
uv run python tiff_panel_app.py test_fig
```

ブラウザが開かない場合は `http://127.0.0.1:8765/` を開いてください。終了は PowerShell で Ctrl+C です。実データを使うときは `test_fig` の代わりに撮影フォルダのパスを指定します。

1. 同じフォルダ内の `名前-dic.tif`・`名前-red.tif`・`名前-green.tif` が1セットになります。サブフォルダと `.tiff` にも対応します。
2. DIC を基準に、Red と Green を右・下方向の整数 px で調整します。「Green の自動候補を計算」は Red に対する候補を提示します。反映後は DIC 上の重ね合わせも使い、細胞の対応を確認してください。
3. DIC・V（Red）・R（Green）・Merge の2行2列の編集画面で、共通の切り抜き枠をドラッグします。各パネルの明るさとコントラストを調整できます。Merge は調整済みの V と R を重ねたうえで、Merge 用の調整を適用します。比較する条件では枠サイズと表示設定を揃えてください。Black / White レベルの 0〜1000 は TIFF の画素型の範囲を基準とする相対値です。
4. 横1列のプレビューを確認して ZIP をダウンロードします。ZIP には文字なしの PNG、TIFF と `recipe.json` が入ります。同じ入力フォルダで JSON を読み込むと、明るさ・コントラストを含む設定を復元できます。旧版の JSON も読み込めます。

入力にスケールバーが焼き込まれている場合は、切り抜き枠をその位置から外してください。出力は図版用の8-bit RGBで、定量には元の TIFF を使ってください。従来の全視野 Red/Green 合成は引き続き `merge_tiff_picture.py` で実行できます。

重なりを拡大して確認するには、画面上部の「拡大率」に 100〜800% を入力します。4枚が切り抜き枠を中心に同じ倍率で拡大されます。「視野を移動」をオンにするか Shift を押しながらドラッグすると、枠を保ったまま4枚の表示位置を移動できます。「枠を中央に」で枠の位置に戻り、「全体表示」で100%に戻ります。拡大率は編集画面の表示にのみ適用されます。
